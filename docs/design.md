# Sova: дизайн

Значок-глаз в строке меню. Не даёт MacBook уснуть при закрытой крышке, пока работают ИИ-агенты, и темнит экран, чтобы он не светил и не тратил батарею. Заменяет форк Insomnia (16 тысяч строк). Цель: около 850 строк кода, около 25 содержательных тестов, 0% процессора в простое, не больше 3% во время сессии.

## Решения Александра (31.10.2026, дополнено 06.11.2026)

- Новая папка и новый git: `~/Documents/Вайбкодинг/Программы macos/Sova`. На GitHub не выкладываем без отдельной команды.
- Имя: **Sova**. Bundle id `com.ungurenko.sova`.
- Заряд ниже **15%** без зарядки: сессия заканчивается.
- Перегрев: «критический» заканчивает сессию сразу, «серьёзный» дольше 5 минут тоже.
- Сессия может идти без ограничения: «12 часов», «24 часа» и «Пока не остановлю» (05.11.2026 отменяет прежний потолок 8 часов).
- Экран во время сессии не гаснет по-настоящему, а темнеет (яркость 0): при закрытой крышке и после простоя из системной настройки. Причина (06.11.2026): любой сон экрана блокирует Мак, а блокировка отрезает агентов от рабочего стола; системное «Требовать пароль» программа поменять не может (sysadminctl отвечает MKBDeviceSetGracePeriod error -14 даже с паролем, `defaults` не действует). Галочка «Затемнять экран во время сессии» включена по умолчанию; при внешнем мониторе крышку не трогаем.
- Иконка приложения (06.11.2026): вариант «Рассвет» — тёмный глаз на янтарном фоне, ресницы как лучи. Исходник `Resources/AppIcon.svg`, из него собирается `Resources/AppIcon.icns` в сетке macOS (1024, поле 100, скругление 185). Строка меню остаётся глазом.

### Rules.swift (чистая логика)

```swift
enum StopReason: Equatable { case finished, manual, lowBattery(percent: Int), overheated, quit }
struct Battery: Equatable { var percent: Int; var onBattery: Bool }   // на настольном Маке батареи нет → nil

enum Verdict: Equatable {
    case keep(recheckAt: Date?)     // nil = таймер не нужен, ждём только событий
    case stop(StopReason)
}

struct DurationOption: Equatable { let label: String; let seconds: TimeInterval? }   // nil = без конца

struct Rules {
    static let batteryFloor = 15                 // стоп при percent < 15 и onBattery
    static let seriousHeatGrace: TimeInterval = 300
    static let durations: [DurationOption]       // 30 минут … 24 часа, «Пока не остановлю»
    let endsAt: Date?                            // nil = сессия без ограничения
    private(set) var hotSince: Date?             // с какого момента «серьёзный» или «критический»
    mutating func thermalChanged(_ state: ProcessInfo.ThermalState, at: Date)
    func verdict(at now: Date, battery: Battery?, thermal: ProcessInfo.ThermalState) -> Verdict
}
func countdownText(_ seconds: TimeInterval) -> String   // «2:41:05»
```

Порядок проверок в `verdict`: время вышло (если `endsAt` есть) → `.finished`; `.critical` → `.overheated`; жар не спадает 5 минут → `.overheated`; батарея на разряде ниже 15% → `.lowBattery`; иначе `.keep(recheckAt: min(endsAt, hotSince+300))`, где `nil` означает «таймера нет».

### SleepHold.swift (root и журнал)

```swift
protocol SleepHold {
    func engage(until: Date?) throws  // nil = без конца; журнал → pmset 1 → сверка чтением
    func release() throws             // pmset 0 → удалить журнал; если pmset упал, журнал остаётся
    func recoverLeftover()            // при старте: журнал остался от прошлого запуска → release()
}
struct PmsetHold: SleepHold {
    static let neverEnds: Date        // 31.12.9999 — так «без конца» выглядит в журнале
    init(journal: URL, run: @escaping (String, [String]) throws -> (status: Int32, output: String))
}
```

Порядок важен для надёжности: журнал (`~/Library/Application Support/Sova/session`, одна строка: время конца в секундах от 1970, для сессии без конца — `253402300799`) пишется **до** включения настройки и удаляется **после** её выключения. Тогда сбой в любой точке не оставляет настройку без следа. Единственная команда с root: `/usr/bin/sudo -n /usr/bin/pmset -a disablesleep 1|0` с таймаутом 10 секунд.

### Controller.swift

```swift
@MainActor final class SessionController {
    enum State: Equatable {
        case idle(last: Outcome?)
        case active(endsAt: Date?)       // nil = без конца
        var isActive: Bool
    }
    struct Outcome: Equatable { var reason: StopReason?; var error: String? }
    private(set) var state: State
    var onChange: () -> Void
    init(hold: SleepHold, now: @escaping () -> Date, battery: @escaping () -> Battery?,
         thermal: @escaping () -> ProcessInfo.ThermalState, notify: @escaping (String) -> Void)
    func start(seconds: TimeInterval?)   // nil = без конца; новая сессия, старая заменяется
    func stop()                          // вручную
    func conditionsChanged()             // вызывают события батареи, температуры, пробуждения и таймер
    func shutdown()                      // выход из программы: вернуть сон
}
```

Один таймер: после каждого изменения ставится на `recheckAt`. Если `recheckAt == nil` (сессия без конца, жара нет), таймер снимается. В простое таймеров нет совсем.

### Экран: темнеет, но не блокируется

При `pmset -a disablesleep 1` Мак не спит с закрытой крышкой, но экран остаётся включённым. Любой настоящий сон экрана (по простою или по крышке) блокирует Мак, а блокировка мешает агентам. Поэтому во время сессии:

- `ScreenKeeper` держит assertion `PreventUserIdleDisplaySleep` (IOKit): система сама экран по простою не выключает. Assertion снимается в конце сессии; если Sova упала, система снимает его сама.
- Затемнение: встроенному экрану ставится яркость 0 через приватную `DisplayServices` (`DisplayServicesSetBrightness`, как у клавиш яркости). Исходная яркость пишется в `~/Library/Application Support/Sova/brightness` до затемнения и возвращается после; `recoverLeftover` при запуске возвращает её, если прошлый запуск упал с тёмным экраном. Если экран уже был чёрным, ничего не трогаем. Если функции нет, экран остаётся светлым, в лог идёт запись.
- Когда темнить: `IdlePolicy` (чистое правило) — сессия идёт и простой не меньше значения `displaysleep` из `pmset -g` (0 = никогда, нет значения = 10 минут); `LidPolicy` — сессия идёт, галочка включена, крышка закрыта, внешнего монитора нет. Любое нажатие или открытие крышки возвращает яркость.
- `LidMonitor` подписывается на `IOPMrootDomain` через `kIOGeneralInterest`. Константа `kIOPMMessageClamshellStateChange` собирается в коде как `err_system(0x38) | err_sub(13) | 0x100`; бит 0 аргумента означает «крышка закрыта». Для проверок вне уведомления читается `AppleClamshellState`. Внешний монитор определяется через `CGGetActiveDisplayList` и `CGDisplayIsBuiltin`.
- Опроса вне сессии нет. Во время сессии `ScreenKeeper` раз в секунду проверяет простой (таймер снимается вместе с сессией).
- `Settings` хранит галочку в `UserDefaults` под ключом `turnDisplayOffOnLidClose`, по умолчанию `true`; она управляет и затемнением по крышке, и по простою. Assertion держится в любом случае.
- Флаг запуска `--idle-dim-seconds N` сокращает простой для проверки.
- Приём с крышкой взят из Modafinil (narcotic-sh/modafinil, MIT).

### Система вокруг

- Батарея: `IOPSNotificationCreateRunLoopSource`, срабатывает только когда меняется процент или включают зарядку.
- Температура: `ProcessInfo.thermalStateDidChangeNotification` → `conditionsChanged()` и `LidMonitor.evaluate()`.
- Пробуждение: `NSWorkspace.didWakeNotification` → `conditionsChanged()` и `LidMonitor.evaluate()`.
- Смена дисплеев: `NSApplication.didChangeScreenParametersNotification` → `conditionsChanged()` и `LidMonitor.evaluate()`.
- Меню: секундный таймер работает **только пока меню открыто** (`menuWillOpen` / `menuDidClose`). Галочка «Затемнять экран во время сессии» читается из `Settings` при каждом открытии.
- Сигналы SIGTERM/SIGINT/SIGHUP → `shutdown()`.
- Уведомления: `UNUserNotificationCenter`, только при автоматическом конце (время, батарея, перегрев).

## Сторож (защита от падения)

`~/Library/LaunchAgents/com.ungurenko.sova.guard.plist` запускает `guard.sh` при входе и каждые 60 секунд. Скрипт ничего не проверяет по подписям и не запускает Sova.

```
нет файла session                 → выйти, ничего не трогать (чужую настройку не касаемся)
время конца в будущем И Sova жива → выйти
иначе                             → sudo -n pmset -a disablesleep 0, удалить файл, дописать строку в ~/Library/Logs/Sova.log
```

Сессия без конца пишется в журнал как `253402300799` (31.12.9999), для сторожа это просто будущее время. Контракт между программой и сторожем один: формат файла `session` (число секунд, одна строка). Скрипт в тестах получает подмену `pmset` и путь к папке через переменные окружения.

## Права

Один раз: файл `/etc/sudoers.d/sova` с двумя строками для `pmset -a disablesleep 1` и `pmset -a disablesleep 0` (аргументы прописаны целиком, шаблонов нет). Ставит `install.sh` через системное окно пароля (`osascript ... with administrator privileges`), проверка `visudo -cf` до установки, файл собирается и проверяется от root в `mktemp`, поэтому подменить его до установки нельзя.

Затемнение экрана и запрет его сна работают от имени пользователя и в sudoers не входят.

## Рассмотрено и отброшено

- **B. Сторож внутри сессии**: программа запускает дочерний скрипт, который следит за ней и возвращает сон. Не закрывает перезагрузку и отключение питания, всё равно нужна служба. Отброшено.
- **C. Всё в одном файле, без чистых правил** (как Sleepless). Нечего тестировать, решения про заряд и жар прячутся в кнопках. Отброшено.
- **D. Служба с правами администратора и связью по XPC** (как Lidless). Нужны подпись разработчика, одобрение в настройках и втрое больше кода. Отброшено.
- **Настоящий сон экрана (`pmset displaysleepnow`, `displaysleep`)**: блокирует Мак, а отключить блокировку программа не может (sysadminctl: `MKBDeviceSetGracePeriod error -14`, `defaults write askForPassword` не действует). Заменён затемнением яркости.
- **Опрос `AppleClamshellState` раз в секунду**: проще, но нарушает цель «0% процессора в простое». Отброшено в пользу уведомления IOKit.
- **Затемнять и внешний монитор**: в clamshell-режиме внешний экран нужен работающим. Отброшено.
- Выбрано **A**: `Rules` (решения) отдельно от `SleepHold` (root) и от интерфейса. Служба — крошечный скрипт без зависимостей.

## Известные ограничения (по итогам проверок 31.10.2026 и 05.11.2026)

- **Перезагрузка посреди сессии.** Сторож работает от имени пользователя и запускается после входа в систему. Если Мак перезагрузился при включённой настройке (сбой, отключение питания) и ждёт пароль на экране входа, сон вернётся только после входа. Системная служба с правами администратора закрыла бы это, но добавляет файл от root и больше кода. Не делаем, пока не понадобится.
- **Зависшая команда pmset.** Команды `pmset` выполняются в главном потоке с таймаутом 10 секунд. Если команда зависла, меню замирает до 10 секунд на вызов. В обычной работе вызов занимает миллисекунды.
- **Гонка сторожа и новой сессии.** Если сторож действует ровно в миллисекунды, когда пользователь запускает новую сессию, сторож может вернуть сон при «активной» сессии. Мак при этом уснёт, это безопасная сторона. Журнал новой сессии сторож не стирает, если у неё другое время конца (проверяется тестом). У двух сессий без конца журнал одинаковый (`253402300799`), поэтому теоретически сторож может удалить свежий журнал; окно — миллисекунды, и это тот же безопасный исход.
- **Внешний монитор.** В clamshell-режиме внешний экран не трогаем: при закрытой крышке он остаётся включённым. Управления внешним монитором в программе нет.
- **Экран темнеет не всегда.** Если IOKit-уведомление о крышке не пришло или `DisplayServices` недоступна, экран останется светлым. Ошибка пишется в системный лог (`NSLog`), сессия продолжается.
- **Яркость после падения.** Если Sova упала при тёмном экране, яркость вернётся при следующем запуске Sova или клавишами яркости; сторож (shell) её не трогает. Сон экрана при этом снова обычный, и Мак заблокируется как всегда.
- **Подсветка клавиатуры и тачбар** не затемняются: управляется только яркость встроенного экрана.
- **Блокировка.** Во время сессии экран не засыпает, поэтому Мак не блокируется сам. Если человек закроет и откроет крышку, заблокирует руками (Ctrl+Cmd+Q) или экран уснёт после конца сессии, действует системная настройка «Требовать пароль»: сейчас «сразу».
- **Исправлено по проверке 31.10.2026:** журнал не стирается, если после неудачного включения сон остался выключенным (хранитель читает настоящее состояние через `pmset -g`); неудачная замена идущей сессии сбрасывает старый таймер; `--seconds` принимает только 1…86400; установка ждёт реального выхода старой копии и повторяет загрузку службы; удаление выполняет всё от администратора одной командой и ничего не стирает, если сон вернуть не удалось.
- **Исправлено по проверке 05.11.2026:** смена конфигурации дисплеев перепроверяет крышку; `uninstall.sh` удаляет настройку из UserDefaults; тест сторожа проверяет, что журнал живой сессии остался; ошибка списка дисплеев пишется в лог.

## Тесты (содержательные)

Ниже — проверяемые поведения; один тест может проверять несколько.

Rules: (1) в пределах времени держим, `recheckAt` = конец; (2) по концу времени `.finished`; (3) 15% держим, 14% на разряде стоп; (4) 10% на зарядке держим; (5) настольный Мак без батареи; (6) `.critical` стоп сразу; (7) «серьёзный» 4:59 держим, 5:00 стоп, `recheckAt` = hotSince+300; (8) жар спал за 4 минуты, счётчик сброшен; (9) `countdownText`; (10) сессия без конца не заканчивается и не просит таймер; (11) батарея 14% и критический жар её останавливают; (12) «серьёзный» жар даёт перепроверку через 5 минут и остановку на 5:00.
SleepHold: (13) журнал создаётся до `pmset 1`; (14) `pmset 1` упал при выключенной настройке, журнала нет; (15) `pmset 1` упал, но сон уже выключен прошлой сессией, журнал помечен «0» для сторожа; (16) macOS проигнорировала включение, сессия не объявляется; (17) `pmset 0` упал, журнал остался и помечен «0»; (18) `recoverLeftover` возвращает сон; (19) сессия без конца пишется в журнал как `253402300799`.
Controller: (20) заряд упал, сессия закончена, уведомление ушло; (21) старт с пустой батареей; (22) `engage` упал, состояние покоя с текстом ошибки; (23) неудачная замена идущей сессии сбрасывает таймер; (24) ручная остановка и выход тихие; (25) `release` упал, об этом сообщено громко; (26) сессия без конца активна, батарея 14% её заканчивает; (27) замена timed↔unlimited сохраняет сон и меняет конец.
LidPolicy: (28) экран темнеет только при всех четырёх условиях.

Сторож (shell, `scripts/test-guard.sh`): девять случаев: нет файла, идёт сессия, время вышло, программа мертва, журнал «0», sudo отказал, новая сессия началась во время работы сторожа, сессия без конца при живой программе, сессия без конца при мёртвой программе. В случаях «не трогать» проверяется, что журнал живой сессии остался.

## Как проверяем «готово» на реальном Маке

1. `./scripts/install.sh`, один раз пароль в системном окне. Установка завершает текущую сессию — это ожидаемо.
2. Простой: `top -l 5 -pid <pid>` показывает около 0%.
3. Сессия `--seconds 90`: `pmset -g` показывает `SleepDisabled 1`, процессор не выше 3%, после конца `SleepDisabled 0`, файл `session` удалён.
4. Сессия «Пока не остановлю»: в меню нет обратного отсчёта, `pmset -g` показывает `SleepDisabled 1`, файл `session` содержит `253402300799`. После «Остановить» — `SleepDisabled 0`, файла нет.
5. Падение: сессия (в том числе без конца), `kill -9`, через 60–70 секунд `SleepDisabled 0` и строка в `Sova.log`.
6. Крышка: сессия, фоновый скрипт пишет метку времени каждые 5 секунд, Александр закрывает крышку на 2 минуты. Яркость падает в 0, в метках нет дыр, в `pmset -g log` нет сна. После открытия крышки яркость и экран прежние, пароль не просят.
7. Внешний монитор: сессия, крышка закрыта, подключён внешний экран — встроенный не трогаем; отключаем внешний экран, не открывая крышку, — встроенный должен потемнеть.
8. Галочка: включена по умолчанию, сохраняется после перезапуска. Выключенная галочка отключает затемнение: экран остаётся светлым и по крышке, и по простою.
9. Старый Insomnia удаляется только после слова Александра (служба, правило sudoers, программа).
