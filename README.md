# Sova 🦉

Значок-глаз в строке меню macOS. Пока идёт сессия, MacBook не засыпает даже с закрытой крышкой, а экран темнеет, но не блокируется. Нужен, чтобы ИИ-агенты (Claude Code, боты) продолжали работать в рюкзаке.

Замена форка Insomnia: примерно 850 строк кода вместо 16 тысяч.

## Как пользоваться

1. Клик по глазу, выбрать «Не давать спать»: от 30 минут до 24 часов или «Пока не остановлю».
2. Глаз открывается, в меню идёт обратный отсчёт. У сессии без ограничения вместо отсчёта надпись «Не спит, пока не остановлю».
3. Во время сессии экран не засыпает по-настоящему, поэтому Мак не блокируется и агенты видят рабочий стол. Вместо сна Sova опускает яркость встроенного экрана в ноль: при закрытой крышке и после простоя, который стоит в настройках Мака («Выключать экран»). Яркость возвращается от любого нажатия или при открытии крышки. Всё это выключает галочка «Затемнять экран во время сессии». Если подключён внешний монитор, при закрытой крышке его не трогаем.
4. По концу времени, при заряде ниже 15% без зарядки или при перегреве сессия заканчивается сама, приходит уведомление. «Остановить» в меню заканчивает её вручную.

## Установка и удаление

```bash
./scripts/install.sh      # один раз спросит пароль Мака в системном окне
./scripts/uninstall.sh    # убирает всё, включая правило sudoers
```

## Как это устроено

Подробно в [docs/design.md](docs/design.md). Коротко:

- `SovaCore`: правила «когда закончить» (чистая логика), хранитель сна (`sudo -n pmset -a disablesleep 1|0`), состояние сессии, правила «когда затемнять экран» (крышка, простой).
- `Sova`: значок, меню, события батареи и температуры, уведомления, монитор крышки (IOKit), `ScreenKeeper` (запрет сна экрана и яркость), галочка в настройках.
- `scripts/guard.sh`: сторож, запускается раз в минуту. Если программа упала или Мак перезагрузился посреди сессии, возвращает сон. Чужие настройки сна не трогает.
- Права: `/etc/sudoers.d/sova`, ровно две команды, без шаблонов. Яркость и запрет сна экрана работают без root.
