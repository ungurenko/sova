# Sova 🦉

Значок-глаз в строке меню macOS. Пока идёт сессия, MacBook не засыпает даже с закрытой крышкой. Нужен, чтобы ИИ-агенты (Claude Code, боты) продолжали работать в рюкзаке.

Замена форка Insomnia: примерно 600 строк кода вместо 16 тысяч.

## Как пользоваться

1. Клик по глазу, выбрать «Не давать спать: 30 минут … 8 часов».
2. Глаз открывается, в меню идёт обратный отсчёт.
3. По концу времени, при заряде ниже 15% без зарядки или при перегреве сессия заканчивается сама, приходит уведомление. «Остановить» в меню заканчивает её вручную.

## Установка и удаление

```bash
./scripts/install.sh      # один раз спросит пароль Мака в системном окне
./scripts/uninstall.sh    # убирает всё, включая правило sudoers
```

## Как это устроено

Подробно в [docs/design.md](docs/design.md). Коротко:

- `SovaCore`: правила «когда закончить» (чистая логика), хранитель сна (`sudo -n pmset -a disablesleep 1|0`), состояние сессии.
- `Sova`: значок, меню, события батареи и температуры, уведомления.
- `scripts/guard.sh`: сторож, запускается раз в минуту. Если программа упала или Мак перезагрузился посреди сессии, возвращает сон. Чужие настройки сна не трогает.
- Права: `/etc/sudoers.d/sova`, ровно две команды, без шаблонов.

## Проверка
